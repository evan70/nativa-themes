Minimálny PHP 8.5 starter kit

Malý a čitateľný základ: modulárny monolit, per-module SQLite, routovanie na atribútoch a prísna bezpečnosť — postavené od nuly.

Menej vrstiev

Zero dependencies

Žiadny Composer runtime, žiadny framework. Hand-rolled PSR-4 autoloader nabootuje aplikáciu aj bez vendor/ — celý produkčný runtime tvorí 5 PHP extensions.

Čitateľný povrch

C-pattern: žiadny magic, žiadne service locatory, žiadne generované mapy. Každý riadok vieš prečítať a overiť — žiadna čierna skrinka.

Per-module SQLite

Jeden databázový súbor na modul — users.db, config.db, locales.db. Žiadna infraštruktúra, žiadny ORM, žiadna migračná sieť.

PHP 8.5 + OPcache/JIT

Prekompilácia na úrovni jazyka: OPcache drží opcody v pamäti, JIT prekladá horúce cesty do natívneho strojového kódu.

Dáta cez C

SQLite je celé v C — najrýchlejšia cesta k dátam bez ORM vrstvy. Built-in funkcie PHP sú prekompilované C knižnice.

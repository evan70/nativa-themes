Nativa Minimal

Four themes, one contract.

Every theme in Nativa Minimal is a self-contained module behind one interface — sixteen methods, from shell chrome to one per page surface. The pages below are hand-written markup wearing each theme's real BEM vocabulary, styled by the theme's real stylesheet.

  • 16 methods per theme
  • 0 runtime dependencies
  • ES2015 Chrome 70 baseline
  • AA contrast, both schemes

How this gallery is built

No screenshots, no re-implementations. The stylesheets and scripts on every page are the theme's own, copied out of the application repository by a sync script; the markup is hand-written to the same class names the PHP templates emit. Change a token upstream, sync, and the gallery changes with it.
